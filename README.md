# sistema-rh
Sistema de RH

API REST de gestão de Recursos Humanos multiempresa: várias empresas usam o mesmo sistema, cada uma com seus próprios setores, cargos e funcionários.

Projeto em desenvolvimento, feito para estudo e prática de back-end Java.

Tecnologias
Java
Spring Boot (Spring Web, Spring Data JPA, Validation)
Hibernate
MySQL
Maven
Postman (testes da API)

O que já está pronto

 Setores (CRUD por empresa)
 Cargos (CRUD por empresa)
